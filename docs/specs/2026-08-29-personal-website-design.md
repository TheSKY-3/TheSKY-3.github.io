## 3. 视觉设计（深色科技风）

- **配色**：深蓝灰底（`#0a0f1a` 一族，非纯黑）；主强调色 teal/cyan；正文浅灰白，对比度满足 WCAG AA；辅助微渐变光晕。
- **字体**：中文系统字体栈（PingFang SC / Microsoft YaHei fallback）；关键数字与技术标签用等宽字体（mono），"1015 万""40.37%""60 期"等数字放大突出。
- **布局**：区块化卡片、细边框微发光；板块编号/锚点导航；桌面优先、移动端完整可用。
- **动效**：克制——滚动渐入、卡片 hover 微亮；不引入重型动画库，CSS 即可实现。

## 4. 技术架构

- **框架**：Astro（当前最新稳定版，实施时以官方文档为准；纯静态输出）。选型原因：组件化 + 路由，为后续扩展博客留结构；同时纯静态输出、部署零门槛。
- **样式**：手写原生 CSS（CSS 变量做主题令牌），不用 UI 框架——深色定制主题手写更可控、零额外依赖。
- **内容组织**：项目/研究内容用 Astro 组件 + TS 数据模块承载；项目详情用动态路由（`/projects/[slug]`）。
- **项目位置**：`D:\个人知识库\个人网站\`（vault 外，遵循知识库"代码不入 vault"维护原则）。
- **前置步骤**：安装 Node.js LTS（当前机器未安装；通过 winget 或便携版安装，由助手执行）。
